# Специфікація проєктування системи (DDS)

## 1. Вступ

### 1.1 Мета документа
Описує архітектуру та технічні рішення, що реалізують вимоги з документа [SRS](SRS.md).

### 1.2 Область застосування
Документ призначений для розробників, тестувальників і архітекторів проєкту.

## 2. Архітектура системи

### 2.1 Загальна схема
Система побудована за клієнт-серверною архітектурою:
- **Клієнт** – вебзастосунок (SPA).
- **Сервер** – REST API.
- **База даних** – реляційна СКБД PostgreSQL.

### 2.2 Основні компоненти

| Компонент | Призначення |
|-----------|-------------|
| Auth Service | Реєстрація, автентифікація (у т. ч. через Google), зміна пароля |
| User Service | Керування обліковими записами користувачів |
| API Gateway | Маршрутизація запитів, обмеження навантаження |

## 3. Модель даних
- **User** (id, email, password_hash, created_at)
- **Session** (id, user_id, token, expires_at)

## 4. Безпека
- Паролі зберігаються лише у вигляді хешу (bcrypt).
- Підтримується двофакторна автентифікація.
